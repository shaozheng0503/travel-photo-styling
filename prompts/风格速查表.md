> 用途：拿到一张照片 → 查类型 → 选风格 → 拼命令。也可按标签反查。

### 各类型选择理由（简注）

- **人物人像**：S3 最稳——L1 原样保留面部/发型/服装身份，L2 提取人物局部贴纸，L4 也能徽章化；S5 原文明确设计了"方形面部+下颌线+块面五官"，是几何化人像的正统玩法；S6 需要人名/主题词做字形钩子；S4 只取"人物局部"（手、服饰、随身物），整人主体不适合。
- **城市地标/建筑**：S5 原文有建筑专属条款（方整体量/立面分区/窗洞节奏/结构转折）；S6 城市名/地标名天然是有力的字形（TOKYO、长城）；S3-L4 珐琅徽章吃建筑轮廓；S4 仅取"建筑特征"做元素。
- **自然风景**：S3-L3 水彩对风景最出效果；S5 大场景块面化会丢细节层级，慎用；S6 风景难提炼单词（除非用情绪词如"寂静"）。
- **生活场景/街拍/室内**：S4 就是为此设计的（咖啡店、桌面、市集 → 拆 4-7 个收藏元素）；S3-L2/L3 吃场景叙事关系；S5 多元素场景会被压得过碎。
- **食物/饮品**：S4 把食物当收藏物拍出亚克力质感最强；S6 可用品名（LATTE、拉面）；S3 层层都能带，但食物做主视觉偏弱。
- **动物/宠物**：S5 动物几何形体（猫→方块猫）效果拔群；S3-L4 徽章轮廓强；S6 品种名/宠物名。
- **器物/静物/产品**：S5 结构感最强（静物几何化解构是经典平面玩法）；S3-L4 做纪念徽章；S4 做收藏图鉴；S6 品名/品牌词。
- **植物/花卉**：都可用但都不突出，S3-L2 贴纸和 S4 植物元素稍好；S6 不建议。
- **交通工具**：S3-L4 轮廓辨识度高（电车、飞机徽章）；S5 体块感强。
- **人+景旅行照**：S3 的设计初衷（旅行叙事+四层风格演化）；S4 记忆册属性天然契合；S1 是 T2I，不能吃照片，但可填同一国家名做文章的封面头图搭配使用。

## 五、三问速判流程

1. **主体是"单体"还是"多元素场景"？**
   单体（人/建筑/器物/动物）→ S5 或 S6；多元素场景（街拍/桌面/市集）→ S4。
2. **要不要严格保留人物身份？**
   要 → S3（L1 基准层锁身份）；不要，允许艺术变形 → S5。
3. **有没有能提炼的"文字钩子"？（人名/地名/品名/情绪词）**
   有 → S6；没有 → 放弃 S6。

拿不准就默认 **S3**：它是全主体适用 + 带原片基准层，翻车率最低。

## 六、按类型的命令模板

```bash
# 人物人像 → 四层转译（保身份）
python make_queue.py 03_四层风格转译_I2I.txt "C:/照片路径.jpg" --model gpt-image-2

# 生活场景 → 亚克力 SceneMap
python make_queue.py 04_亚克力SceneMap_I2I.txt "C:/照片路径.jpg" --model gpt-image-2

# 建筑/器物 → 几何解构（nano-banana-2 色彩更高级，贵 4 积分）
python make_queue.py 05_几何解构_I2I.txt "C:/照片路径.jpg" --model nano-banana-2

# 有文字钩子 → 字体图像化
python make_queue.py 06_字体图像化_I2I.txt "C:/照片路径.jpg" --model gpt-image-2

# 文生图封面（填占位符后手动单行入队）
# 01: [COUNTRY]/[国家] 替换成国家名 → gpt-image-2
# 02: [城市/国家]/[标志性地标]/[本地建筑]/[城市] 替换 → nano-banana-2
```

入队后：`python <repo>/imagifly.py --validate && --estimate`，确认再跑。

## 七、注意事项

- **S1/S2 是 T2I**：不吃参考图，占位符必须先替换；适合做文章封面/头图，与 I2I 产物搭配。
- **成本**：gpt-image-2=3/张，nano-banana-2 1k=7、2k=14/张；S5 建议 nano-banana-2 时成本翻倍以上。
- **模型 slug 别手打**：跑批前 `--list-models` 核对（slug 写错会静默 fallback 扣费，见 SKILL 坑 21）。
- **参考图**：S3/S4/S5/S6 均支持 ≤3 张，多图会互相稀释主体，一般 1 张最稳。
