# 提示词技能库

9 套实战迭代过的旅行照片风格化模板，分两类：

- **`t2i/` 文生图**（2 套）：不需要照片，填占位符生成海报/概念图
- **`i2i/` 图生图**（7 套）：吃一张参考照片，输出风格化设计海报

每套模板都经过多轮真实生成迭代，包含防翻车条款（禁裁切、贴纸去重、地名复用、日期季节化等，见各文件内嵌说明）。

## 快速使用

### 方式一：CLI 渲染入队（推荐）

```bash
# 图生图：模板 + 参考图 → 单行队列条目
python main.py --render i2i/03a_记忆贴纸_单层_I2I.txt --img 你的照片.jpg --add
python main.py --render i2i/03b_水彩票根_单层_I2I.txt --img 你的照片.jpg --add

# 文生图：填好占位符后渲染（[COUNTRY]=日本 直接改在文件里或渲染后改 prompts.txt）
python main.py --render t2i/01_手绘旅行海报_T2I.txt --add

# 检查 + 跑
python main.py --validate
python main.py
```

### 方式二：直接喂给任意生图工具

模板就是纯文本提示词，ChatGPT / 即梦 / 豆包 / 任何图生图产品里直接粘贴 + 传照片即可，不绑定本项目 CLI。

## 三问速判（选哪个模板）

1. **手上有照片吗？** 没有 → t2i/ 两套；有 → i2i/
2. **照片主体是什么？** 人+景旅行照 → 03/04/05；建筑 → 03/08/09；生活场景 → 07；器物静物 → 06/08
3. **想要什么气质？** 治愈收藏 → 04/05/07；高级编辑 → 08/09；纪念感 → 06；全家桶 → 03

## 防翻车条款（内嵌在模板里）

这些条款是真实翻车后加的，别删：

- **禁裁切**：上半部分原图必须完整呈现每个主体（曾发生牌坊+车被裁掉）
- **贴纸去重**：六枚贴纸与主视觉互不重复（曾发生小黄鸭出现两次）
- **地名逐字复用**：票根文字必须与照片上的文字严格一致（曾发生"光亚"写成"光正"）
- **DATE 季节化**：用 SUMMER/2026 等季节表达，不编造具体日期
- **昼夜氛围保持**：夜景照片的下层风格转译保持夜色调性
